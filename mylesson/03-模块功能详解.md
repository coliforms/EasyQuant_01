## 1. 引擎与状态（回测的"心脏"）

| 文件 | 职责 | 关键内容 |
|------|------|---------|
| [engine.py](file:///e:/VScode_projects/EasyQuant_01/eqlib/engine.py) | **回测引擎**：事件循环、调度器、订单撮合、组合管理、生命周期钩子 | `run_backtest()`、`run_daily/run_weekly/run_monthly`、`run_selection`、`set_benchmark/set_option/set_order_cost/set_slippage`、`record`、`run_paper_trade`、涨跌停/停牌/退市处理 |
| [_state.py](file:///e:/VScode_projects/EasyQuant_01/eqlib/_state.py) | **状态管理**：每个回测一个独立 `BacktestSession`，用线程本地存储支持并发 | `BacktestSession`、`get_session()`、`reset()` |
| [context.py](file:///e:/VScode_projects/EasyQuant_01/eqlib/context.py) | **上下文对象**：策略运行时能拿到的数据 | `Context`（当前日期、portfolio、universe）、`Portfolio`（现金/持仓/总市值）、`Position`（数量/成本/市值） |
| [constants.py](file:///e:/VScode_projects/EasyQuant_01/eqlib/constants.py) | **全局常量**：集中管理金融参数，改一处全局生效 | 无风险利率 `RISK_FREE_RATE=0.03`、年交易日 `TRADING_DAYS_PER_YEAR=244`、各板块涨跌停比例、退市天数 |
| [logger.py](file:///e:/VScode_projects/EasyQuant_01/eqlib/logger.py) | 日志对象 | `log`（全局日志） |

**一句话理解**：`engine.py` 是主循环，`_state.py` 是"记忆"，`context.py` 是"眼前看到的账户"，`constants.py` 是"规则参数"。

## 2. 交易与订单对象

| 文件 | 职责 | 关键内容 |
|------|------|---------|
| [trade.py](file:///e:/VScode_projects/EasyQuant_01/eqlib/trade.py) | **下单执行**：把策略的买卖意图变成订单，缓冲到次日成交 | `order`（按股数）、`order_target`（调到目标股数）、`order_value`（按金额）、`order_target_value`、`order_lots`（按手）、`order_pct`（按比例）、`cancel_order`；T+1 检查、100 股取整、手续费 |
| [objects.py](file:///e:/VScode_projects/EasyQuant_01/eqlib/objects.py) | **基础对象** | `GlobalObject`（即 `g`，存策略变量）、`Order`（订单状态机 pending→filled 等）、`OrderCost`（手续费/印花税计算） |
| [slippage.py](file:///e:/VScode_projects/EasyQuant_01/eqlib/slippage.py) | **滑点模型**：模拟成交价偏离理想价 | `FixedSlippage`（固定百分比）、`VolumeSlippage`（随成交量占比变大）、`SlippageModel`（基类，无滑点） |

**关键设计**：订单在策略回调里只是"入队"（pending），真正的成交由引擎在**下一交易日开盘**撮合（避免前视偏差）。

## 15. 核心 API 速查（最常用的一页）

```python
from eqlib import *            # 一键导入所有公共 API

# 生命周期
run_backtest(initialize, ...) / run_strategy(initialize, ...)
run_daily(func, time='every_bar') / run_weekly(...) / run_monthly(...)

# 配置
set_benchmark('000300.XSHG') / set_option(...) / set_order_cost(...) / set_slippage(...)

# 数据
get_price(...) / history(...) / attribute_history(sec, count, '1d', ['close'])
get_all_securities() / get_index_stocks(...) / get_industry_stocks(...)

# 交易
order(sec, amount) / order_target(sec, amount) / order_value(sec, cash)
order_target_value(sec, cash) / order_lots(sec, lots) / order_pct(sec, pct)

# 全局与上下文
g.security = '601390'          # 存变量
context.portfolio.available_cash / context.portfolio.positions

# 记录与报告
record(price=..., cash=...) / generate_chart(...) / generate_html_report(...)

# 分析
analyze_returns(result) / brinson_attribution(...)

# 工具
utils.macd(...) / utils.rsi(...) / utils.boll(...) / utils.kelly_criterion(...)
```

> 更多 API 细节，见官方 [docs/reference/](file:///e:/VScode_projects/EasyQuant_01/docs/reference) 或 [eqlib/__init__.py](file:///e:/VScode_projects/EasyQuant_01/eqlib/__init__.py) 的导出与 docstring。
