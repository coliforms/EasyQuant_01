# 项目框架总览（EasyQuant / eqlib）

## 一、这个项目是什么（一句话）

**EasyQuant（库名 `eqlib`）是一个用 Python 写的"中国 A 股事件驱动量化回测框架"。**

你只需写一段"买卖规则"（叫**策略**），框架就帮你用**历史行情**模拟交易，告诉你"如果当年真按这个规则操作，会赚还是亏、风险多大"，并生成图表报告。API 风格对齐 JoinQuant / Zipline（`initialize` → `run_daily` → `handle_data`）。

## 二、前置概念小词典（零基础必读）

量化/股票术语很多，先搞清这几个，读代码就不懵：

| 术语 | 大白话解释 | 在代码里的体现 |
|------|-----------|---------------|
| **回测（backtest）** | 用过去的数据"假装"交易一遍，看策略历史表现 | `run_backtest()` / `run_strategy()` |
| **策略（strategy）** | 你的买卖规则，本质是两个函数 | `initialize()` + `handle_data()`/`market_open()` |
| **K线 / bar** | 某段时间的开盘、最高、最低、收盘、成交量 | `attribute_history()` 返回的 `open/high/low/close/volume` |
| **股票代码（security）** | 唯一标识一只股票，如 `601390`，带交易所后缀如 `601390.XSHG`（沪）/`000858.XSHE`（深） | `g.security` |
| **基准（benchmark）** | 用来对比的参照物，如沪深300 `000300.XSHG` | `set_benchmark()` |
| **收益率** | 赚/亏的百分比 | `analyze_returns()` 的 `total_return` |
| **回撤（drawdown）** | 从历史最高点跌下来的幅度 | `max_drawdown` |
| **夏普比率（Sharpe）** | 每承担一份风险换回多少收益，越高越好 | `sharpe_ratio` |
| **手续费/印花税** | 交易要交的成本（佣金、卖出印花税） | `set_order_cost()`、`OrderCost` |
| **滑点（slippage）** | 想买的价和实际成交价的差 | `set_slippage()`、`eqlib/slippage.py` |
| **T+1** | A 股规则：当天买的股票，第二天才能卖 | 引擎撮合时强制检查 |
| **涨跌停** | A 股规则：一天最多涨/跌一定比例（主板±10%等） | 引擎拦截 | 
| **前视偏差（look-ahead bias）** | 用"未来才知道的信息"做当前决策（作弊） | 订单次日开盘成交来规避 |
| **过拟合（overfitting）** | 策略"背下了历史答案"，换个时间段就不灵 | `eqlib/scientific/`、`wfa.py` |

## 四、一次回测的完整数据流（时序）

```
1. 你定义 initialize(context)
        │
        ▼
2. run_backtest() 创建 Context、加载历史数据
        │
        ▼
3. 每个交易日循环：
        │
        ├─ before_trading_start（可选，开盘前）
        ├─ handle_data / market_open（你的买卖逻辑：取数据→算信号→order* 下单）
        │        │
        │        ▼
        │   订单进入"待成交队列"（pending）
        │
        ├─ after_trading_end（可选，收盘后）
        │
        ▼
4. 下一交易日开盘：撮合队列里的订单
        ├─ 涨跌停拦截（涨停买不进/跌停卖不出）
        ├─ 停牌处理（无行情 → 当日取消）
        ├─ 退市清算（连续 30 个交易日无行情 → 强制卖出）
        └─ 按 T+1、100 股取整、手续费、滑点结算
        │
        ▼
5. 回测结束：analyze_returns() 计算指标 → generate_report() 出报告
```

> **关键设计**：信号（今天）与成交（明天开盘）分离，就是为了**避免前视偏差**。

## 六、核心设计理念（理解这些，就读懂了项目灵魂）

1. **事件驱动**：不是"一次性算完"，而是每个交易日调用一次你的函数。好处是代码像真人交易一样逐日决策。

2. **避免前视偏差**：今天算出的信号，到**下一交易日开盘**才成交。否则等于"作弊"。

3. **贴近 A 股真实规则**：
   - T+1（当天买次日卖）
   - 一手 100 股取整
   - 涨跌停拦截（主板 ±10%、创业板/科创板 ±20%、ST ±5%、北交所 ±30%）
   - 停牌取消、退市清算
   - 印花税按日期区分（2023-08-28 后卖出 0.05%）

4. **可复现 & 可并发**：每个回测用独立的 `BacktestSession`（线程本地），多个回测可并行跑而不互相干扰（见 [eqlib/_state.py](file:///e:/VScode_projects/EasyQuant_01/eqlib/_state.py)）。

5. **分层解耦**：用户只接触策略 API，引擎/数据/报告内部实现可各自演进。
