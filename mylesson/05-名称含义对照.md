# 方法 / 名称含义对照表（随查随用）

> 读 EasyQuant 代码时，遇到不认识的英文名称，回来这里对照。
> 说明：很多"方法名"本质是英文单词的缩写或拼凑，看懂词根就记住了。

---

## 一、框架名

| 名称 | 拆解 | 含义 |
|------|------|------|
| **EasyQuant** | Easy + Quant | 简单 + 量化 → "轻松做量化" |
| **eqlib** | e(q) + lib | EasyQuant 的 **lib**rary（库）的缩写 |

---

## 二、策略生命周期方法（API 对齐 JoinQuant / Zipline）

| 名称 | 拆解 | 含义 |
|------|------|------|
| `initialize` | initial + ize | 初始化（回测开始只跑一次，做准备工作） |
| `run_daily` | run + daily | 每天运行（注册"每天要执行的函数"） |
| `run_weekly` | run + weekly | 每周运行 |
| `run_monthly` | run + monthly | 每月运行 |
| `handle_data` | handle + data | 处理数据（每个时间点处理行情的函数） |
| `market_open` | market + open | 开盘（市场 9:30 开门，你写的买卖函数名） |
| `set_benchmark` | set + benchmark | 设置基准（拿来对比业绩的指数） |
| `set_option` | set + option | 设置选项 |
| `set_order_cost` | order + cost | 设置手续费 |
| `set_slippage` | slippage | 设置滑点（成交价与预期价的偏差） |
| `record` | record | 记录（把指标记下来，用于画图） |
| `order` | order | 下单 |
| `order_value` | order + value | 按"金额"下单（买多少钱的） |
| `order_target` | order + target | 按"目标股数"下单（调到指定仓位） |
| `before_trading_start` | before trading start | 开盘前（每天交易开始前执行） |
| `after_trading_end` | after trading end | 收盘后（每天交易结束后执行） |

## 四、pandas 方法（读数据必查）

| 名称 | 拆解 | 含义 |
|------|------|------|
| `df` | DataFrame 缩写 | 一张表格（Data + Frame = 数据框架） |
| `Series` | series | 表格中的"一列"数据 |
| `df['close']` | 方括号取列 | 取出 close 这一列 |
| `.iloc[...]` | i + loc | 按**位置**取值（integer location） |
| `.loc[...]` | loc | 按**标签/名字**取值（location） |
| `[-1]` | 负数索引 | 倒数第 1 个（最后一个） |
| `[-2]` | 负数索引 | 倒数第 2 个（昨天） |
| `.rolling(N)` | rolling | 滚动窗口（取连续的 N 天） |
| `.mean()` | mean | 求平均值 |
| `.sum()` | sum | 求和 |
| `.max()` / `.min()` | max / min | 最大 / 最小 |
| `.std()` | standard deviation | 标准差（衡量波动大小） |
| `.tail(N)` | tail | 最后 N 行 |
| `.head(N)` | head | 前 N 行 |
| `.dropna()` | drop + NA | 去掉空值（NaN） |
| `.pct_change()` | percent change | 涨跌幅（相对上一行的百分比变化） |
| `.empty` | empty | 判断是否为空 |
| `len(df)` | length | 表格行数 |
| `.astype(float)` | as + type | 转换数据类型 |
| `.cumprod()` | cumulative product | 累计相乘（算净值） |
| `.cummax()` | cumulative max | 累计最大值（算回撤） |
| `.columns` | columns | 列名 |
| `.to_string()` | to string | 转成文本方便打印 |
| `.reset_index()` | reset index | 重置行号 |
| `.reindex()` | re + index | 重新对齐索引 |

## 六、常见变量名习惯

| 名称 | 拆解 | 含义 |
|------|------|------|
| `security` | security | 证券（这里指一只股票，如 `601390`） |
| `g` | global | 全局变量对象（存策略参数，全程共享） |
| `hist` | history 缩写 | 历史数据 |
| `north` | north | 北向资金（香港流入 A 股的钱） |
| `ma` | Moving Average | 移动平均线（均线） |
| `fast_ma` | fast + ma | 快均线（短期均线，如 5 日，反应灵敏） |
| `slow_ma` | slow + ma | 慢均线（长期均线，如 20 日，反应迟缓） |
| `current_price` | current + price | 当前价格（最新一天的价格） |
| `prev_fast` | previous fast | 昨天的快线值 |
| `curr_fast` | current fast | 今天的快线值 |

## 七、量化术语（扫盲必读）

| 名称 | 拆解 | 含义 |
|------|------|------|
| `backtest` | back + test | 回测（用历史数据模拟交易，看策略是否赚钱） |
| `strategy` | strategy | 策略（你的买卖规则） |
| `benchmark` | benchmark | 基准（拿来对比的指数，如沪深 300） |
| `drawdown` | draw + down | 回撤（账户从最高点跌了多少） |
| `return` | return | 收益率 |
| `fee / commission` | fee | 手续费 |
| `slippage` | slippage | 滑点（想买 10 元，实际 10.02 元，差的就是滑点） |
| `T+1` | T + 1 | 今天买的股票，明天才能卖 |
| `limit up / down` | limit | 涨跌停（涨跌幅限制 ±10%） |
| `look-ahead bias` | look ahead | 前视偏差（偷看未来数据的错误，回测要避免） |
| `north money flow` | north money flow | 北向资金（外资通过沪/深股通买入 A 股） |
| `golden cross` | golden cross | 金叉（快线向上穿过慢线 → 买） |
| `death cross` | death cross | 死叉（快线向下穿过慢线 → 卖） |
| `bar` | bar | K 线（一根 = 某段时间的开高低收量） |
| `OHLCV` | O H L C V | 开、高、低、收、成交量 五个字段的缩写 |
| `momentum` | momentum | 动量（价格趋势的强弱） |
| `position` | position | 仓位（你持有多少股票） |
| `portfolio` | portfolio | 投资组合（你的账户整体） |
| `cash` | cash | 现金（账户里还没买股票的闲钱） |

> 记忆技巧：多数方法名是「动词 + 名词」或「两个单词缩写」，先认词根（如 `get` 获取、`set` 设置、`run` 运行、`daily` 每天），再看后缀，基本能猜出七八成。
